## Overview

MB-7 Mixer splits audio into seven bands and hosts any VST or AU plugin in each band, enabling per-band parallel processing with any third-party effect for ultimate multiband flexibility.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Blue Cat MB-7 Mixer** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Seven Bands** | Configurable crossover points dividing the signal into up to 7 bands |
| **Plugin Host** | Load any VST/VST3/AU plugin into each band as the band processor |
| **Parallel Mode** | Full parallel processing with individual band level and pan |
| **Mid/Side** | Optional M/S processing mode for mastering and stereo manipulation |
